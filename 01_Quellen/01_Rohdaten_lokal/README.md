# Rohdaten lokal

**Pfad:** `Website_und_Anwendungen/01_Quellen/01_Rohdaten_lokal`

## Zweck

Vertrauliche Originalquellen. Der Inhalt wird NICHT in Git übernommen (siehe .gitignore); nur die READMEs bleiben versioniert.

## Gehört hierher

- Unbearbeitete Exporte und Originale.

## Gehört nicht hierher

- Fertige Dokumente und Freigaben.

## Regeln

- Dateinamen: `JJJJ-MM-TT_Thema_vN.ext`, mit Umlauten, ohne Leerzeichen, keine „(1)“-Kopien.
- Nichts endgültig löschen: Abgelöstes kommt ins Archiv.
- Enthält dieser Ordner nur diese README und wird nicht gebraucht, räumt ihn die Projektabschluss-Prüfung auf (nach deiner Bestätigung).
