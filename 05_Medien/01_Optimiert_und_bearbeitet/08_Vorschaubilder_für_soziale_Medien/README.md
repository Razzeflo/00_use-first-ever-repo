# Vorschaubilder für soziale Medien

**Pfad:** `Website_und_Anwendungen/05_Medien/01_Optimiert_und_bearbeitet/08_Vorschaubilder_für_soziale_Medien`

## Zweck

Vorschaubilder, die beim Teilen der Seite erscheinen (Open Graph).

## Gehört hierher

- Bilder im Format 1200×630.

## Gehört nicht hierher

- Beitragsbilder für Kanäle (gehören nach 04_Marketing_und_Vertrieb).

## Regeln

- Dateinamen: `JJJJ-MM-TT_Thema_vN.ext`, mit Umlauten, ohne Leerzeichen, keine „(1)“-Kopien.
- Nichts endgültig löschen: Abgelöstes kommt ins Archiv.
- Enthält dieser Ordner nur diese README und wird nicht gebraucht, räumt ihn die Projektabschluss-Prüfung auf (nach deiner Bestätigung).
