# Medien

**Pfad:** `Website_und_Anwendungen/05_Medien`

## Zweck

Alle Bilder, Logos, Icons, Schriften und weitere Medien der Website. Originale des Kunden bleiben in der Kundenakte (05_Kundenmaterial).

## Gehört hierher

- Bearbeitete und optimierte Medien in Exportformaten.

## Gehört nicht hierher

- Originale vom Kunden (liegen im Kundenordner unter 05_Kundenmaterial).

## Regeln

- Dateinamen: `JJJJ-MM-TT_Thema_vN.ext`, mit Umlauten, ohne Leerzeichen, keine „(1)“-Kopien.
- Nichts endgültig löschen: Abgelöstes kommt ins Archiv.
- Enthält dieser Ordner nur diese README und wird nicht gebraucht, räumt ihn die Projektabschluss-Prüfung auf (nach deiner Bestätigung).
