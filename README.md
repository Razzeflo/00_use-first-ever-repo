# USE-FIRST-EVER-REPO

Standard-Startrepository für neue Projekte in `flowding`.

## Leitprinzipien
1. Nummerierte Struktur
2. Trennung von Quellen, Doku, AI-Arbeit, Design, Code, Betrieb
3. Verbindliche Templates
4. Nachvollziehbarkeit über Source-Log und Entscheidungen

## Kernregeln
- Rohquellen zuerst nach `01_sources/01_raw_inputs/`
- Quellenherkunft in `01_sources/03_source_register/01_source-log.md`
- PRD/Lastenheft/UX-Template verpflichtend nutzen
- Agent-/Skill-Arbeit nur in `03_ai_work`
- Veraltetes nach `11_archive` verschieben
