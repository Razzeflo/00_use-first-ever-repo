# Dokumentationsregeln (Projektstandard)

## Grundregeln
1. Jede Entscheidung mit Datum + Begründung dokumentieren.
2. Anforderungen versionieren, nicht überschreiben.
3. Quellenherkunft immer im Source-Log erfassen.
4. Markdown-Dateien in klaren Templates führen.
5. Offene Punkte als Checkliste pflegen.

## Schreibstil
- Präzise, kurz, überprüfbar.
- Keine unklaren Begriffe ohne Glossar.
- Anforderungen testbar formulieren („System muss … wenn … dann …“).

## Pflicht-Metadaten pro Doc
- Titel
- Version
- Datum
- Autor
- Status (Draft/Review/Final)
