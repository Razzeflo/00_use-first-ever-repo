# Meta-Daten und strukturierte Daten

**Pfad:** `Website_und_Anwendungen/02_Dokumentation/12_Suchmaschinenoptimierung_und_KI-Sichtbarkeit/02_Meta-Daten_und_strukturierte_Daten`

## Zweck

Titel, Beschreibungen und strukturierte Daten (Schema.org) je Seite.

## Gehört hierher

- Meta-Tabellen, JSON-LD-Vorlagen.

## Gehört nicht hierher

- Seitentexte.

## Regeln

- Dateinamen: `JJJJ-MM-TT_Thema_vN.ext`, mit Umlauten, ohne Leerzeichen, keine „(1)“-Kopien.
- Nichts endgültig löschen: Abgelöstes kommt ins Archiv.
- Enthält dieser Ordner nur diese README und wird nicht gebraucht, räumt ihn die Projektabschluss-Prüfung auf (nach deiner Bestätigung).
