# Abläufe

**Pfad:** `Website_und_Anwendungen/02_Dokumentation/09_Abläufe`

## Zweck

Wichtige Abläufe über mehrere Systeme hinweg.

## Gehört hierher

- Ablaufdokumentationen mit Quellenverweisen (Source Map).

## Gehört nicht hierher

- Einzelne Systeme (gehören nach 08_Systeme).

## Regeln

- Dateinamen: `JJJJ-MM-TT_Thema_vN.ext`, mit Umlauten, ohne Leerzeichen, keine „(1)“-Kopien.
- Nichts endgültig löschen: Abgelöstes kommt ins Archiv.
- Enthält dieser Ordner nur diese README und wird nicht gebraucht, räumt ihn die Projektabschluss-Prüfung auf (nach deiner Bestätigung).
